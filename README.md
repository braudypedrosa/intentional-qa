# Intentional QA

Intentional QA helps you review websites with a structured, evidence-focused approach. It can perform one focused check or bring everything together in a complete website QA review.

## What it can check

- Responsive behavior across screen sizes
- Broken links and missing resources
- Forms and validation messages
- Important user journeys
- Accessibility and keyboard usability
- Page errors and failed requests
- Website performance
- SEO and sharing information
- Visual and content consistency
- Visible security and privacy concerns

## Ways to use it

Ask for one focused review:

> Use Intentional QA to check the responsiveness of this website.

> Use Intentional QA to find broken links across this site.

> Use Intentional QA to test every public form without sending live submissions.

Or request the complete suite:

> Use Intentional QA Full QA to audit this website and prepare a complete report.

## What you receive

Intentional QA reports what was tested, what passed, what failed, what could not be tested, and what needs attention first. Findings include enough context and evidence for another person to understand and reproduce the issue.

## Safe by default

Website reviews are read-only unless you explicitly request changes. Intentional QA avoids sending live forms, creating accounts, placing orders, making payments, or triggering other real-world actions without clear permission.

## Who it is for

Intentional QA is useful for website owners, QA testers, developers, agencies, product teams, and anyone preparing a website for launch or reviewing an existing site for problems.
