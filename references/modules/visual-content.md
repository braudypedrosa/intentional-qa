# Visual & Content Consistency

Review the rendered interface for consistency and comprehension while keeping subjective concerns separate from functional failures.

## Visual checks

- Header/footer consistency, hierarchy, spacing rhythm, alignment, typography, line length, component states, imagery, crops, icons, controls, dialogs, tables, cards, empty states, and error states.
- Consistency across templates for buttons, labels, colors, focus/hover/disabled states, breadcrumbs, notices, and calls to action.
- Readability, scanning order, content density, misleading affordances, competing actions, and visually hidden essential information.

## Content checks

- Placeholder or missing copy, obvious spelling/grammar defects, stale dates, inconsistent naming, incorrect contact/legal information, broken downloads, empty cards, duplicated content, and locale/currency/date/time-zone inconsistencies.
- Dynamic totals, filters, sorting labels, result counts, and visible content matching the selected state.

Classify overlap, clipping, missing information, unreadable contrast, and unusable controls as defects when verified. Classify taste, polish, hierarchy preferences, and editorial recommendations as Concerns unless requirements establish an objective failure.

## Output

Group template-wide issues by root cause. Include rendered evidence and page/state. Keep editorial recommendations and visual concerns outside confirmed functional totals.
